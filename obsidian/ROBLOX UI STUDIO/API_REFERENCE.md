## list_documents

List all design documents in the workspace (id, name, revision, counts).

_No parameters._

## create_document

## inspect_design

Describe a document: pages, screens, full node tree with ids, explicitly-set properties and computed absolute boxes (x,y relative to the screen, w×h in px), components, tokens and animations. Use format 'json' for the raw stored nodes of a subtree. Call this before editing an existing design.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `documentId` | string | yes | Document id (from list_documents / create_document) |
| `nodeId` | string |  | Limit to this subtree |
| `depth` | integer |  |  |
| `format` | "outline" \| "json" \| "spec" |  | outline (default), json (stored nodes) or spec (NodeSpec you can edit and re-create) |
| `includeLayout` | boolean |  | Include computed boxes (default true) |

## create_element

Create a subtree from a NodeSpec (or several via `specs`, or a preset via `preset`). parentId omitted = top level of the page (loose frame). Returns the root id(s) and a name→id map of every created GUI object. Specs are validated fully before anything is applied.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `documentId` | string | yes | Document id (from list_documents / create_document) |
| `parentId` | string |  | Node reference: id ("n_…"), name path ("Screen/MainFrame/Title") or unique name |
| `pageId` | string |  |  |
| `index` | integer |  | Child index (default: append) |
| `spec` | any |  | NodeSpec: { className, name?, props?, children?: NodeSpec[], tokens?, component?, overrides?, notes?, corner?, stroke?, gradient?, padding?, list?, grid?, pages?, aspect?, scale?, sizeConstraint?, textSizeConstraint? }. See get_schema / CLAUDE_INTEGRATION.md. |
| `specs` | any[] |  |  |
| `preset` | string |  | Preset id from get_schema (e.g. 'shop-card'); merged with `spec.name`/`spec.props` if given |
| `canvas` | object |  | Canvas position for top-level nodes |
