## Bugs found & fixed (root causes)
1. **Grid showed one column**: ScrollingFrame canvas used CanvasSize literally (0 width). Roblox's AbsoluteCanvasSize is at least the window → `max(window, CanvasSize)`.
2. **Text overlapping a button in a list**: list layouts used the pre-AutomaticSize size. Items with AutomaticSize are now measured by a full placement first.
3. **Dark "art" panels**: UIGradient multiplies the background colour; presets used dark bases → white base.
4. **Gradient buttons**: in Roblox the gradient tints the text of the same object → label moved to a child TextLabel.
5. **Preset inserted into a TextLabel**: `containerFor` accepted any GuiObject → now only frame-like containers.
6. **Loose frame renders offset twice**: renderer already positions relative to the root → removed the extra wrapper.
7. **e2e process didn't exit**: explicit `process.exit` after cleanup.

## Lessons
- Check Roblox semantics (gradient multiplication, canvas min size) before blaming the renderer.
- Avoid `pkill -f`/`pgrep -f` with patterns that match the invoking shell; use pidfiles.
